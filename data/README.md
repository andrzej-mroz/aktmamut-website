# Local data factory

This directory contains the local Python data-generation pipeline used by AKT Mamut.

The full contents are intentionally excluded from Git because they include large source datasets, GPX files, intermediate files, generated backups and local configuration.

The local data factory is preserved on the development machine and remains the source for generating the JSON and GeoJSON files consumed by the website.

Only this README is tracked in Git.

Credentials, secrets and environment files must never be committed.
