# Mobile Vision

## Philosophy

AKT Mamut is not intended to be a responsive copy of the desktop website.

Desktop and mobile serve different purposes.

- Desktop is for planning, exploration, analysis and storytelling.
- Mobile is a field companion used during expeditions.

Both experiences share the same data and codebase, but may present different user interfaces.

---

## Desktop Experience

Desktop remains a traditional website.

Main characteristics:

- Full navigation bar
- Hero section
- Rich content
- Maps, statistics and articles
- Footer on Home page

---

## Mobile Experience

The mobile version should feel like the home screen of an application rather than a small website.

Goals:

- No scrolling on first screen
- No Hero section
- No traditional navigation bar
- Immediate access to the main functions

Layout:

AKT MAMUT logo

🗺 Expeditions

🏔 Challenges

📊 Statistics

📖 Manual

Each item is presented as a large touch-friendly card.

---

## Design Principles

Mobile first means field first.

Every action should be reachable within one tap.

The interface should be usable:

- outdoors
- in sunlight
- with one hand
- while wearing gloves

Beauty is important.

Speed is more important.

---

## Long-term Vision

Desktop becomes the planning and exploration environment.

Mobile becomes the expedition companion.

Both remain a single Astro project sharing the same data model.
